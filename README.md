# AI App Generator

A full-stack AI-powered dynamic runtime application builder developed using MERN stack technologies with multilingual support.

---

## 🚀 Live Demo

Frontend:
https://ai-app-generator-client.onrender.com

Backend:
https://ai-app-generator-c1qi.onrender.com

---

## 📌 Features

- User Registration & Login
- JWT Authentication
- Dynamic Runtime UI Rendering
- Multi-language Support
  - English
  - Hindi
  - Telugu
  - Spanish
  - German
- Dashboard Rendering
- Dynamic Forms
- Dynamic Tables
- CSV Upload Support
- Prisma + PostgreSQL Database
- Responsive Premium UI

---

## 🛠 Tech Stack

### Frontend
- React.js
- Vite
- React Router DOM
- Axios
- i18next
- React Hot Toast

### Backend
- Node.js
- Express.js
- Prisma ORM
- PostgreSQL (Neon DB)
- JWT Authentication
- bcryptjs

### Deployment
- Render
